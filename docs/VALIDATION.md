## README alignment and remaining limitations

The README's implemented CSV checks, scatter plots, pairwise sensitivity, rule-based
report, optional local open-weight model, and runtime-loaded Skill all work in the
verified local workflow.

The rule-based recap is intentionally fixed Python logic; the separately labeled AI
explanation is generated by Ollama. The distinction is visible in the UI.

Remaining limitations:

- Model text is not automatically fact-checked. The observed 1B output repeated
  thresholds despite being asked not to, and did not explicitly describe the numerical
  before/after reversal. The tables remain the authoritative computed evidence.
- Autonomous tool selection, multi-step planning, durable memory, significance tests,
  and a publicly hosted demo remain outside the implemented scope, as README states.
- The current Streamlit emits non-fatal `use_container_width` deprecation notices;
  rendering and tests pass. A future dependency update should migrate this API while
  updating the supported minimum Streamlit version.
- This local run does not prove Windows or the CI Python-version matrix passes;
  those environments were not run here.
- No real/original student dataset was available, so results apply to the synthetic fixture.
